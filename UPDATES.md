# Автообновление игры (exe)

Как это работает: игра при запуске (и раз в 30 минут) смотрит на твоём сайте файл `latest.yml`.
Если там версия новее — в игре появляется плашка «Доступно обновление» → «Обновить» → скачивание → «Перезапустить».
Скачивается только изменённая часть файла (blockmap), а не вся игра целиком.

## Один раз
В `package.json` замени адрес в `build.publish[0].url` на папку своего сайта, например `https://мой-сайт.com/pcmaster/`.
Это адрес папки, где лежат файлы обновления (с косой чертой на конце).

## На каждый выпуск
1. Создай тег с новой версией (GitHub → Releases → Draft a new release → тег `v1.2.0`) или запусти сборку вручную.
   Версия берётся из тега (v1.2.0 → 1.2.0). Она ДОЛЖНА быть больше предыдущей, иначе обновление не появится.
2. Когда сборка закончится, скачай 3 файла и положи в папку на сайте:
   - `PC-MASTER-Setup-1.2.0.exe`
   - `latest.yml`
   - `PC-MASTER-Setup-1.2.0.exe.blockmap`
3. Всё. У игроков при следующем запуске появится плашка.

## Важно
- Обновления работают только в установленном приложении (не при `npm start` и не в браузере).
- Сайт с файлами должен отдавать их по обычной ссылке (https). Если сайт закрыт паролем, приложение не сможет скачать:
  оставь папку с обновлением доступной по прямой ссылке, а закрыть можно страницу с кнопкой скачивания.
- Первая установка (Setup.exe) ставится вручную, дальше всё само.
