Структура проекта
index.html            точка входа, подключает скрипты по порядку
main.js, preload.js   Electron (оболочка для exe)
three.min.js          создаётся из npm (prepare.js)
graphics/             только вид: свет, тени, улица, небо, эффекты, модели-код, загрузчик
logic/                логика и физика: игроки, заказы, сюжет, сохранения, звук (код)
ui/                   меню, пауза, настройки
models/ textures/ audio/ data/   готовые файлы ресурсов
tools/                запекание моделей (в игру не входит)
Смешанные файлы (графика + логика вместе: world.js, chars.js, chars2.js) будут разделяться постепенно.
